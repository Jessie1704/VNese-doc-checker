# A.7. Commit gì, bỏ qua gì {#c-a7}

## Nguyên tắc

```
PHẦN DÙNG CHUNG ──▶ commit
phương pháp · claim registry · trạng thái · audit · artifact

PHẦN RIÊNG CỦA TỪNG NGƯỜI VÀ TỪNG MÁY ──▶ bỏ qua
con trỏ session · trạng thái dẫn xuất cục bộ
```

Công cụ cài sẵn một file `.gitignore` theo nguyên tắc này. Thường bạn không cần sửa gì.

## Commit

| Đường dẫn | Vì sao |
| --- | --- |
| `aidlc/spaces/<đội>/memory/` | Cách làm việc của đội, dùng chung |
| `aidlc/spaces/<đội>/knowledge/` | Tài liệu bạn đưa vào |
| `aidlc/spaces/<đội>/codekb/` | codekb: quét một lần, cả đội dùng |
| `aidlc/spaces/<đội>/intents/*/aidlc-state.md` | Trạng thái workflow |
| `aidlc/spaces/<đội>/intents/*/audit/` | Audit trail |
| `aidlc/spaces/<đội>/intents/*/<phase>/` | Artifact của từng stage |

> **Ghi chú:** Với brownfield, nên commit codekb. Sinh codekb tốn công, và nếu mỗi người tự quét lại thì vừa lãng phí vừa dễ dẫn tới mỗi người hiểu hệ thống một kiểu.

## Bỏ qua

| Đường dẫn | Vì sao |
| --- | --- |
| `aidlc/.aidlc-sessions/` | Liên kết session, riêng từng máy |
| Con trỏ space và intent đang dùng | Riêng từng người |
| Trạng thái dẫn xuất cục bộ | Sinh lại được |
