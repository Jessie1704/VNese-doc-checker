# A.3. Lệnh và cờ {#c-a3}

> **Ghi chú:** Tiền tố gọi lệnh khác nhau theo harness. Bảng này viết `/aidlc`; trên Codex CLI, đổi thành `$aidlc`. Xem [02](#c-02).

Nguồn: `docs/guide/12-cli-commands.md` trong tài liệu chính thức của công cụ. Cột cuối là số dòng để tra nguyên văn.

## Bắt đầu và tiếp tục

| Lệnh | Làm gì | Dòng nguồn |
| --- | --- | --- |
| `/aidlc <profile>` | Bắt đầu với profile chỉ định | 138 |
| `/aidlc <mô tả>` | Bắt đầu, để công cụ tự đề xuất profile | 170 |
| `/aidlc compose "<mô tả>"` | Soạn route riêng, chờ bạn duyệt | 192 |
| `/aidlc` | Tiếp tục workflow đang dở | 208 |
| `/aidlc --status` | Xem trạng thái, chỉ đọc | 403 |
| `/aidlc --version` | Phiên bản framework | 1160 |
| `/aidlc --help` | Trợ giúp | 1172 |

## Vòng đời Unit (dành cho đội)

Xem [13b](#c-13b) để biết khi nào dùng lệnh nào.

| Lệnh | Làm gì | Dòng nguồn |
| --- | --- | --- |
| `/aidlc unit status` | Xem Unit nào claim được, đã có người, đang bị chặn | 587 |
| `/aidlc unit participate` | Bật bộ chọn có hướng dẫn cho clone này | 488 |
| `/aidlc unit claim <unit>` | Claim một Unit | 433 |
| `/aidlc unit adopt <unit>` | Tiếp tục việc đã claim từ một clone mới | 456 |
| `/aidlc unit release <unit>` | Trả lại Unit | 471 |
| `/aidlc unit publish <unit>` | Publish bản đã làm xong | 499 |
| `/aidlc unit pin <unit>` | Pin bản ứng viên để duyệt | 511 |
| `/aidlc unit gate <unit>` | Quyết định duyệt hoặc từ chối | 531 |
| `/aidlc unit land <unit>` | Merge vào nhánh tích hợp | 547 |

`claim` và `release` cũng có dạng viết tắt `--claim` / `--release`.

## Lệnh tắt

Một số profile có lệnh tắt dạng `/aidlc-<tên>`. Profile nào có, xem cột cuối của [A.2](#c-a2).

## Lệnh session (chỉ đọc)

Các lệnh này không đẩy workflow đi tiếp và không ghi audit, chạy lúc nào cũng được.

| Lệnh | Làm gì |
| --- | --- |
| `/aidlc-session-cost` | Thời lượng, kết quả từng stage, số lần sensor chạy |
| `/aidlc-replay` | Xem lại những gì đã xảy ra |
| `/aidlc-outcomes-pack` | Đóng gói kết quả; lệnh duy nhất ghi ra file |

## Lệnh hệ thống

Chạy trong shell, không chạy trong harness.

| Lệnh | Làm gì |
| --- | --- |
| `aidlc config --harness <tên>` | Cấu hình dự án cho một harness |
| `aidlc doctor` | Kiểm tra tình trạng cài đặt |

## Gọi trực tiếp công cụ

Không phải lệnh `/aidlc`. Gọi thẳng file công cụ trong thư mục harness; thay `.claude/` bằng thư mục harness của bạn.

| Lệnh | Làm gì | Chương |
| --- | --- | --- |
| `bun .claude/tools/aidlc-utility.ts detect --json` | Quét thư mục, chỉ đọc | [03](#c-03) |
| `bun .claude/tools/aidlc-utility.ts codekb-scope-diff --repo <repo>` | Rerun guard: kiểm tra codekb còn khớp code không | [11](#c-11) |
